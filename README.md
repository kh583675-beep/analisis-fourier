# Análisis de Fourier - Tarea Formativa

Este proyecto implementa la tarea de análisis de señales con Fourier.

## Archivos
- `fourier_tarea.py` : Código en Python que resuelve los 3 incisos.

## Resultados
- a) Suma de 5, 20 y 50 Hz → 3 picos en 5, 20, 50 Hz
- b) Onda cuadrada de 5 Hz → pico en 5 Hz y armónicos impares
- c) Barrido de 1 a 10 Hz → banda entre 1 y 10 Hz

Librerías: numpy, matplotlib
